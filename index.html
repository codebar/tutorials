Web development roadmap

Learn the three core languages of the web, then choose to specialise in what users see (frontend) or what powers it behind the scenes (backend).

Foundations

  1. Get comfortable with the terminal and Git before you write much code. You'll use both every day as a developer.

    • Getting your laptop set up for codebar

    • Introduction to version control

    • Lesson 6 - Advanced HTML5

  3. Make it look good: styling, layouts, and pages that work on any screen size.

    • Lesson 3 - Beyond the basics
    • Lesson 4 - CSS, layouts and formatting

    • Lesson 8 - Building your own app

Choose your route

Frontend

Build the interfaces people see and use.

  1. JavaScript with types, which catches bugs before your users do. Tutorials are planned for this step.

  2. Choose a framework

    • Component-based UIs. The most widely used frontend library.

    • A gentle learning curve and excellent documentation.

    • A full framework with batteries included, common in larger organisations.

Backend

Build the servers, logic and data behind the scenes.

  1. Choose a language

App development roadmap

Foundations

  1. The same toolkit as the web path: a working laptop, the terminal and Git.

    • Getting your laptop set up for codebar
    • Introduction to the command line
    • Introduction to version control

  2. Variables, loops, functions and data structures transfer to every language. Work through whichever of these feels friendlier.
